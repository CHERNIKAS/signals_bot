### 11. Потенциальные проблемы с транзакциями БД
**Местоположение:** `database/database.py`

**Проблема:**
- Использование `with _db_conn() as c` - хорошо
- Но в некоторых местах явные `BEGIN`/`COMMIT`/`ROLLBACK`
- Может быть конфликт между context manager и явными транзакциями

**Пример:**
```python
with _db_conn() as c, c.cursor() as cur:
    cur.execute("BEGIN")  # ← Избыточно, context manager уже управляет транзакцией
    # ...
    cur.execute("COMMIT")  # ← Избыточно
```

**Рекомендация:** Использовать либо context manager, либо явные транзакции, но не оба
